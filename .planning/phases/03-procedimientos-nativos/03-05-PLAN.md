<objective>
El ciclo de vida completo de la versión de una empresa: emitir congelando el
cuerpo, abrir borrador, guardarlo tantas veces como haga falta sin generar basura
de versiones, y publicar degradando la anterior.

Purpose: son tres criterios de la fase a la vez. El 2 (editar la plantilla no
altera lo emitido) se sostiene sobre el snapshot; el 3 (guardar dos veces deja una
versión, publicar crea la siguiente y degrada la anterior) sobre el bucle de
borrador — sin él cada guardado crearía una versión y se llegaría a la 47; y el 4
(historial con versión, fecha, autor, descripción y estatus) sale de columnas que
ya existen, generado en tiempo de render y nunca redactado a mano.
Output: las cuatro acciones y las dos consultas que el plan 03-06 cablea a botones
y el 03-07 pinta en pantalla.
</objective>

```typescript
async function loadCompanyDocumentForWrite(companyDocumentId: string) {
  const row = await db.companyDocument.findUnique({
    where: { id: companyDocumentId },
    select: {
      id: true, companyId: true, documentId: true, version: true, status: true,
      contentHtml: true, codeOverride: true, nameOverride: true,
      sourceTemplateVersion: true, kind: true,
      document: { select: { manualId: true, templateVersion: true, contentHtml: true } },
    },
  });
  if (!row) throw new Error("Documento de empresa no encontrado");
  const assignment = await db.manualAssignment.findUnique({
    where: { manualId_companyId: { manualId: row.document.manualId, companyId: row.companyId } },
    select: { id: true },
  });
  if (!assignment) throw new Error("La empresa no tiene este manual activo");
  const ctx = await requireAssignmentManageAccess(assignment.id);
  return { row, ...ctx };
}
```
