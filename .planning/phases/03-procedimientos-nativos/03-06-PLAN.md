**1. `document-body-editor.tsx`** — cliente. Copia de la maqueta de
`section-content-editor.tsx` con tres diferencias:

a) **Prop discriminada de destino**, para que el mismo componente sirva a la
   plantilla y al borrador de empresa sin pasar server actions por props:
```typescript
type EditorTarget =
  | { kind: "template"; documentId: string }
  | { kind: "company"; companyDocumentId: string };

export function DocumentBodyEditor({
  target,
  initialHtml,
  canImport,
  helpText,
}: {
  target: EditorTarget;
  initialHtml: string;
  /** El importador sólo tiene sentido sobre la plantilla. */
  canImport: boolean;
  helpText: string;
})
```
   Dentro, `handleSave` hace `switch (target.kind)` y llama a
   `updateManualDocumentBody` o a `saveCompanyDocumentDraft`. Los dos imports son
   estáticos: nada de importación dinámica ni de pasar la acción como prop.

b) **Mensaje de guardado que dice lo que pasó**, no un genérico. Para la plantilla,
   usar el `changed`/`templateVersion` que devuelve la acción:
   - `changed: false` → "Sin cambios: el contenido es el mismo que ya estaba
     guardado." Esto es lo que hace visible la política de versión de plantilla y
     evita que alguien crea que el guardado no funcionó.
   - `changed: true` → "Guardado. La plantilla pasa a la versión N."
   Para el borrador de empresa: "Borrador guardado. Sigue siendo la versión N hasta
   que lo publiques."

c) **Importador de `.docx`**, sólo si `canImport`. Un `<label>` con `<input
   type="file" accept=".docx" className="hidden">`, como el "Subir plantilla" de
   `manual-documents.tsx:229-242`. Al elegir archivo:
   - `FormData` → `fetch("/api/upload/document-body", { method: "POST", body })`
   - si `!res.ok`, pintar `data.error` tal cual (la ruta ya devuelve textos en
     español: 400 formato, 413 tamaño, 422 vacío)
   - si va bien, **volcar `data.html` en el textarea y cambiar a vista previa
     automáticamente**, sin guardar. Que el consultor vea qué llegó antes de
     comprometerlo es la diferencia entre importar y sufrir una importación.
   - si `data.droppedImages > 0`, avisar: "Se descartaron N imágenes: el cuerpo del
     procedimiento no las incorpora todavía."
   - un `confirm()` antes de volcar **si el textarea ya tenía contenido**: importar
     reemplaza, y perder media hora de redacción por un clic no es aceptable.

d) **Texto de ayuda**, recibido por prop porque difiere entre plantilla y borrador.
   El de la plantilla añade a la línea de siempre la lista honesta de la
   importación, copiada de `03-03-SUMMARY.md`: las tablas se conservan; los bordes,
   colores, fuentes e imágenes de Word no; los encabezados se remapean.
